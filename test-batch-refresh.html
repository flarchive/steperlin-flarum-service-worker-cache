🚀 Service Worker 批量并发刷新测试

📝 测试说明

v1.3.6 新特性: 批量并发刷新机制

  • 🔄 批量收集: 50ms 内的刷新请求自动合并
  • ⚡ 并发执行: 使用 Promise.all() 并发获取资源
  • 🎯 自动去重: 相同资源不会重复刷新
  • 📊 详细日志: 实时显示批量处理进度和结果

❌ 旧版本 (v1.3.5)

// 每个资源独立刷新
setTimeout(() => {
    refreshCache(request, cacheName);
}, 0);

// 结果: 串行执行
// 20个资源 ≈ 6秒

✅ 新版本 (v1.3.6)

// 批量收集后并发刷新
scheduleRefresh(request, cacheName);

// 执行:
Promise.all([...refreshPromises]);

// 结果: 并发执行
// 20个资源 ≈ 300-500ms
